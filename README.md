# A Basic DevSecOps orientation session

## Just clone this repository as follows
\$ git clone https://github.com/vishworks/devsecops.git  
\$ cd devsecops 

## Create an isolated virtual environment in python (one-time setup)
\$ python -m venv devops-env   

## Activate the virtual environment
\$ source devops-env/bin/activate  
\$ python -m http.server 3000

## Access the content as follows (using your favorite browser)
http://localhost:3000 

## Deactivate the venv once you're done
Ctrl+C to stop the http server  
\$ deactivate
